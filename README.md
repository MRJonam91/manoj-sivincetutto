# SiVinceTutto

Un progetto per consultare i risultati delle estrazioni SiVinceTutto.

## Stato del progetto

Il progetto è in fase di preparazione; l’applicazione non è ancora presente in questa repository.

## Dati e fonti

Consulta l’[archivio ufficiale](https://www.sivincetutto.it/archivio-estrazioni). I dati recenti raccolti localmente sono parziali e non vengono ridistribuiti; uno storico completo va ancora acquisito e verificato.

Le estrazioni sono casuali: frequenze e risultati passati non permettono di prevedere quelli futuri.
